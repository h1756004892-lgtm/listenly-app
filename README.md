# Listenly

A clean starter project for an English listening practice web app.

## Files

- `index.html`
- `package.json`
- `src/App.jsx`
- `src/main.jsx`
- `src/style.css`

## Run locally

```bash
npm install
npm run dev
```

## Current MVP

- Upload a local audio file
- Play/pause/replay
- Playback speed
- Listening mode
- Dictation UI
- Vocabulary saved in browser

The transcript area is deliberately marked as a future speech-to-text integration point. It does not pretend that a fixed demo sentence came from the user's uploaded audio.
